# FeedCraft 🚀

FeedCraft is a modern, scroll-stopping landing page for a social media marketing agency.  
It showcases services, process, platforms, and a call-to-action for potential clients.

## ✨ Features

- Modern dark UI design
- Fully responsive layout
- Services section
- Agency process workflow
- Social media platforms showcase
- CTA booking modal
- Smooth scrolling navigation
- Toast notification on form submit
- Instagram contact integration

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- No frameworks (lightweight & fast)

## 📂 Project Structure

```

feedcraft/
│
├── index.html
├── README.md
├── feedcraft_logo.png
└── assets/ (optional)

```

## 🚀 Getting Started

1. Clone the repository
```

git clone [https://github.com/your-username/feedcraft.git](https://github.com/your-username/feedcraft.git)

```

2. Open `index.html` in your browser

That's it — no dependencies required.
